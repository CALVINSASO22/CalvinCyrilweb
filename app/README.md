# Calvin Cyril App

App personal para habitos, agenda, finanzas y exportacion de actividades al calendario del movil.

## Uso rapido

- Abrir `app/index.html` desde GitHub Pages.
- Crear habitos y marcarlos cada dia.
- Cargar actividades con fecha, hora y aviso.
- Usar `Exportar calendario` para generar un `.ics` e importarlo en Google Calendar o Apple Calendar.
- Registrar finanzas en UYU y USD por separado.

Los datos se guardan localmente en el navegador del dispositivo.
